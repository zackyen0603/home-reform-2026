# home-reform-2026

2026 年居家整修需求與決策紀錄，主要範圍為：

- 1F：門面、玄關、落塵區、客廳隔間與空調預留
- 4F：2 房、2 衛、客廳、餐廳、廚房、儲藏／家事空間
- 共通系統：空調、除濕、電力、照明、智慧家庭與網路

## 四樓電力與燈具檢視

在[互動控制台](https://zackyen0603.github.io/home-reform-2026/#electrical)可依空間、種類與 ID／回路搜尋 81 個點位；點選地圖標記或清單查看回路、電壓、安裝高度與狀態。可切換 2D、3D 俯瞰和第一人稱視角。

- 桌面第一人稱：WASD 或方向鍵移動，拖曳畫面轉向。
- 手機第一人稱：左側方向鍵移動，右半畫面拖曳轉向；3D 俯瞰可拖曳與按 ＋／－ 縮放。
- 手機 2D 圖可左右滑動以維持可點選的標記大小。3D 需要瀏覽器支援 WebGL，無法啟用時仍可切回 2D。
- 位置、種類、回路以 `electrical.yaml` 維護；房間及牆線以 `floorplan.yaml` 維護。頁面不複製第二套點位資料。座標為圖面推估，施工前仍須現場覆核。

## 四樓家具資料與預覽

四樓家具集中於 `furniture.yaml`，每項包含固定 ID、房間 ID、中心點 `[x, y, z]`、長寬高 `size`（公分）、`rotation_deg`、採購狀態、預算及原試算表列號。平面座標與 `floorplan.yaml` 共用左上角原點；`z: 0` 代表家具落地。來源是試算表「★家具購買規劃總表」，尚無明確尺寸者以 `dimension_basis: estimated` 或混合標記明示暫估值。

[互動控制台](https://zackyen0603.github.io/home-reform-2026/#floorplan) 的四樓 2D／3D 預覽預設顯示家具，可用「顯示家具」切換；點選家具或右側清單可查尺寸、位置、採購狀態及來源。電力與燈具視圖也可疊加家具，在第一人稱視角中查看空間佔用。預覽模型是依品項簡化的體積模型，施工與下單前應依選定型號、門片開啟及走道寬度校正座標。

## 目前優先決策

施工圖與管線定位前，優先處理：

1. 1F 玻璃磚尺寸、列數及收邊。
2. 1F 客廳冷氣選擇 5.0kW 或 6.3kW。
3. 1F 客房是否預埋冷媒銅管。
4. 玄關透光拉門款式及五金。
5. 主臥與次臥窗戶採 5mm 或 8mm 玻璃。
6. 廚房水槽選 KL-9477D 或 KL-9776。
7. 廚房背牆採烤漆玻璃或琺瑯板。
8. 80cm 近吸式油煙機型號。
9. 客浴免治便座、兩間恆溫龍頭及暖風機型號。
10. 崁燈尺寸、光束角、調光方式與自購範圍。
11. 智慧開關通訊方式與牆壁端／燈具端分工。
12. 自購、刪除項目與合併工資後的新版總價。

## 更新原則

- 每一項需求使用固定 `id`，後續修改不更換 ID。
- 規格尚未定案時，保留 `options` 並將狀態設為 `evaluating`。
- 會影響管線、開孔、防水或封板的項目設為 `P0`。
- 已購買的設備設為 `purchased`，並保留完整型號。
- 取消項目不刪除，改為 `cancelled`，保留決策歷程。
- 不在儲存庫中保存完整住址、電話或其他不必要的個人資訊。
